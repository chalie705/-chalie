About me

Turning practical problems into working web apps.

I'm a Software Engineering student who enjoys building web applications people can actually use. I like understanding a problem first — who it's for and what slows them down — then breaking it into small, testable pieces.

I work on both sides of the stack: crafting responsive interfaces with HTML, CSS and JavaScript, and building the PHP and MySQL logic that keeps data organised and reliable.

  • Problem-first — understand the need before writing code.
  • Always learning — every project teaches something new.
